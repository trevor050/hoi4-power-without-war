# UI scenario (tests/ui/ui_desk). Run with:
#   python tools/run_hoi4.py --tag GER --size 1920x1080 --leave-running --test tests/ui/ui_desk
# Gives the GER player data on every UI surface, then logs what the UI layer
# derived. Screens are opened by hand or with tests/ui/ui_drive.py.
#   day 1  Wolfram Question (600-day clock) opens (GER claimant); the floating
#          desk and the dossier start open;
#          ledger: SWE->GER steel (committal, 2 civs), GER->ITA coal (open,
#          1 civ), ROM->GER oil (reserved), CZE->YUG steel; demand GER->CZE
#          quiet, steel output share; CZE makes no moves.
#          SWE->ITA steel (committal) and SWE->POL steel (open): ITA and POL
#          dossiers offer to poach them (GER produces steel);
#          GER chairs a coal conference (IRRA runs from day 1; GER is short
#          of rubber, so both cartels show on the Overview).
#   day 3  UI slots logged (situations, ledger, marks on CZE)
#   day 5  GER rubber reserve seeded (600 unit-days): the reserve tick draws it
#   day 33 market report logged (first turn of the month has passed)
#   day 45 reserves and cartel rows logged, PWW_DONE
